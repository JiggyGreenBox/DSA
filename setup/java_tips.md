# Java tips
- classes need to be separate files, better to build a new directory for each project

### Build project folder
 - `Ctrl + Shift + P`
 - `Java: Create Java Project`
 - `No Build Tools`
 - Create folder anywhere and select
 - Add class files in `src/`

### Getters and setters
 - Right click anywhere
 - `Source Action`
 - `Generate Getters and Setters`
