# http vs https
```sh
HTTP and HTTPS differ in security: HTTP (Hypertext Transfer Protocol)
transmits data in plain text and is insecure, while HTTPS (Hypertext Transfer Protocol
Secure) uses SSL/TLS encryption to secure the connection between a user's browser and
a website's server. This means HTTPS protects sensitive information from being
intercepted by hackers. They also use different default ports (\(80\) for HTTP and \(443\)
for HTTPS) and have different URLs (http:// vs. https://). 
```

# ssl/tls
```sh
Both SSL and TLS are communication protocols that encrypt data between
servers, applications, users, and systems. They authenticate two parties connected over
a network so they can exchange data securely.

TLS is the direct successor to SSL, and all versions of SSL are now deprecated.

TLS and SSL both use digital certificates that facilitate the handshake process.

HTTPS is the practice of establishing a secure SSL/TLS protocol on an insecure
HTTP connection.
```
