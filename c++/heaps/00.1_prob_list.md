# The most important thing to learn

When you read a question, I want your brain to ask:

### Pattern 1

```
Need the largest repeatedly?

→ max heap
```

---

### Pattern 2

```
Need the smallest repeatedly?

→ min heap
```

---

### Pattern 3

```
Need the best K?

→ heap of size K
```

---

### Pattern 4

```
Need current maximum/minimum while processing a stream?

→ heap
```

---

### Pattern 5

```
Need to repeatedly choose the next best candidate?

→ heap + greedy
```
