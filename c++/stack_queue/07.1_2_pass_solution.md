for any index idx, 
the contribution to the sum,
is the num of subarrays where idx is minimum


For each index i, how many subarrays have arr[i] as the minimum?
(# choices of start to the left) × (# choices of end to the right)

[3,1,2]
3       +3
3,1     +1
3,1,2   +1
1       +1
1,2     +1
2       +2

3 -> x1

for 3
    start = [0]
    end = [0]
    sum += 3 * start(1) * end(1) = 3

for 1
    start = [0,1]
    end = [1,2]
    sum += 1 * start(2) * end(2) = 3 + 4

for 2
    start = [2]
    end = [2]
    sum += 2 * start(1) * end(1) = 3 + 4 + 2


start = how far left can u go with >= arr[i]
end = how far right can u go with > arr[i]
    Left: <
    Right: <=
    This avoids double counting duplicates.

RIGHT
