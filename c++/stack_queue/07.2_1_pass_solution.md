## start - end - left - right intuition
```sh
for any index idx, 
the contribution to the sum,
is the num of subarrays where idx is minimum


For each index i, how many subarrays have arr[i] as the minimum?
(# choices of start to the left) × (# choices of end to the right)

[3,1,2]
3       +3
3,1     +1
3,1,2   +1
1       +1
1,2     +1
2       +2

3 -> x1
1 -> x4
2 -> x1

for 3
    start = [0]
    end = [0]
    sum += 3 * start(1) * end(1) = 3

for 1
    start = [0,1]
    end = [1,2]
    sum += 1 * start(2) * end(2) = 3 + 4

for 2
    start = [2]
    end = [2]
    sum += 2 * start(1) * end(1) = 3 + 4 + 2
```

## RIGHT / END
```sh
[5,2,1,3,4]

for end, we calculate when we pop 
and not when we push

            = 0 - (-1) = 1    
    end     = cur_idx - pop_idx
            = 1 - 0 = 1

    sum += (arr[pop_idx] * start * end) % mod
        += (5 * 1 * 1) % (1e9+7)
    
    idx[2] = 1
    push(1)
    st = [1]

1
```
