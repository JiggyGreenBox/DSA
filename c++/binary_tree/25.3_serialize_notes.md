# Serialize / Deserialize Binary Tree

---

## DFS (Preorder)

Traversal

```
Root
Left
Right
```

Serialize

```
value,
null,
```

Deserialize

```
read token

null
    return nullptr

node

left

right
```

Time : O(N)

Space : O(H)

---

## BFS (Level Order)

Serialize

```
queue

node
    output value

null
    output null
```

Deserialize

```
root

queue

for every node

read left

read right
```

Time : O(N)

Space : O(N)

---

## When to use

DFS

- Recursive
- Elegant
- Canonical interview solution

BFS

- Level-order representation
- Matches LeetCode array representation
- Easier to visualize
